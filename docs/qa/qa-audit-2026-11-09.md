# QA and security audit (Step 25), 9 November 2026

PocketNyaya on the development copy (MariaDB 10.4, database `pocket`, synthetic data only). This audit records what was actually run and what was found. It isn't a penetration test. An independent penetration test is still needed before launch.

## What was run

| Check | Result |
|---|---|
| Automated test suite | **429 passed**, 0 failed, across authentication, roles, tenant isolation, documents, billing, forum, privacy, ODR, practice closing, integrations, the isolation layer and headers |
| Static analysis (Larastan level 6) | 0 errors |
| Code style (Pint) | Passed |
| PHP dependency advisories (`composer audit`) | None found |
| JavaScript dependency advisories (`npm audit --omit=dev`) | 0 vulnerabilities |
| Routes without sign-in | 14 of 353. All are meant to be public: home, directory, forum reading, disclaimers, invitation landing pages, ping and the health check |
| Unescaped Blade output (`{!! !!}`) | None |
| POST forms without CSRF tokens | None |
| Models open to mass assignment (`$guarded = []`) | None |
| Raw SQL built from variables | None found by pattern search |

| Security headers on the running app | Present, after fix F-4 |

## Findings

Severity: **High** means it must be fixed before real data. **Medium** means before launch. **Low** means it can follow.

| ID | Severity | Area | Finding | Recommended fix | Status |
|---|---|---|---|---|---|
| F-1 | High | Operations | There is no backup of the database, the encrypted files or the encryption keys. Part 2 hasn't run, and everything sits on one disk | Run Part 2, then back up `storage/app/private/documents` and the key folder separately, with an off-site copy in India | **Open: owner action** |
| F-2 | High | Security | The app connects to MariaDB as `root` | The two-connection switch-over is built and tested. Create `pn_app` and `pn_platform` from `php artisan pocketnyaya:isolation-grants`, then set `DB_ISOLATION=true` | **Open: accounts needed** |
| F-3 | High | Security | Document keys are local files (`LocalKeyProvider`). Losing them loses every document, and stealing them with the files exposes the documents | A key management service with escrow, in an Indian region | **Open** |
| F-4 | Medium | Web | No browser security headers were sent (frame, sniffing and content policy) | `SecurityHeaders` middleware. Inline scripts removed so the policy can forbid them | **Fixed** (`9374bf6`) |
| F-5 | Medium | Privacy | A hold on a practice, matter or dispute didn't stop document deletion | Holds now reach the records beneath them (C60 §4.2) | **Fixed** (`9ed5873`) |
| F-6 | Medium | Audit | The daily audit digest wasn't scheduled, so tamper anchors were never written | Scheduled daily at 00:30 India time | **Fixed** (this audit) |
| F-7 | Medium | Configuration | Development settings: `APP_DEBUG=true`, sessions not encrypted, secure cookie not set | The production `.env` in the deployment guide sets these correctly | **Open: at deployment** |
| F-8 | Medium | Accounts | Demo accounts share a published password | Remove `DemoSeeder` users before any real data. Never run it in production | **Open: at deployment** |
| F-9 | Medium | Concurrency | Row locks for invoice numbers, payments, consent and holds aren't exercised by the suite, which runs on one connection (TX-C, CS, RT tests) | Run the approved concurrency tests on staging | **Open** |
| F-10 | Medium | Platform | PHP 8.2 support ends on 31 December 2026, and MariaDB 10.4 is already past end of life | PHP 8.4 with Laravel 13, and MariaDB 10.11 or 11.4 LTS in production | **Open** |
| F-11 | Medium | Files | Uploaded files aren't scanned for malware (`scan_status = skipped`) | Add a scanner such as ClamAV before launch | **Open** |
| F-12 | Medium | Server | This development MariaDB reports missing table files for two other projects (`little-prodigy-revamp`, `sling-website`) | Repair or remove them before running the Part 2 backup, which may fail on them | **Open: owner action** |
| F-13 | Low | Performance | Search uses `LIKE`, and a few screens load up to 200 rows at once | Full-text search (V1) and paging when data grows | **Open** |
| F-14 | Low | Documents | PDFs (invoices, settlements) support Western characters only | A PDF library with Indian-language fonts | **Open** |
| F-15 | Low | Usability | Screens are responsive (Bootstrap grid, viewport set) but weren't checked on real phones | A manual pass on Android and iOS browsers | **Open** |
| F-16 | Low | Legal | Disclaimers, consent wording, screening rules, ODR rules, retention periods, the 30-day privacy deadline, credit notes and reverse charge are drafts | Counsel and a CA review | **Open** |
